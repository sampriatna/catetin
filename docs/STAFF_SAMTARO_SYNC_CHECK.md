**Akun:** `samtaro.space@gmail.com` · Outlet SMT · Kasir

## 1) Pastikan HP pakai build baru

1. Buka **Atur / Pengaturan**.
2. Lihat bagian **Versi aplikasi**.
3. Build harus menampilkan SHA commit terbaru (bukan `dev`).
4. Jika beda / kosong: tap **Muat ulang aplikasi (pakai versi terbaru)**, tunggu reload, cek lagi.

## 2) Pulihkan checklist tanpa isi ulang

Jika SDM / Laporan Omset / Report Sosmed bertuliskan  
**“Belum tersinkron ke pusat — data tetap tersimpan di perangkat.”**:

1. Tap **Sinkronkan sekarang** (bukan “Isi”).
2. Tunggu toast sinkron.
3. Jika pusat sudah punya data → muncul **“Sudah tersimpan di pusat.”** dan checklist hijau.
4. **Jangan** hapus draft. **Jangan** isi laporan baru.

## 3) Jika masih merah

1. Tap ikon ☁️ di beranda sekali.
2. Atau Pengaturan → **Sinkronkan sekarang**.
3. Masih gagal → laporkan ke admin SHA build yang tampil di Pengaturan (jangan isi ulang).
