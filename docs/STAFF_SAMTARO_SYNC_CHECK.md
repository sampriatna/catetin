# Uji HP Samtaro — 5 langkah (jangan isi ulang)

**Akun:** kasir SMT · Production SHA harus `37f6b4b` (atau lebih baru)

1. **Pengaturan → Versi aplikasi** — pastikan SHA = Production (`37f6b4b`…). Jika beda, tap **Muat ulang aplikasi (pakai versi terbaru)**.
2. Di checklist, pada **Laporan Omset** (dan SDM/Sosmed jika merah) tap **Sinkronkan sekarang** / **Proses** — **jangan hapus draft, jangan isi ulang**.
3. Tunggu toast; idealnya muncul **Sudah tersimpan di pusat** dan checklist hijau.
4. **Refresh** halaman (atau tutup–buka app), pastikan tetap selesai.
5. Konfirmasi ke admin: pusat hanya **1 laporan omzet** untuk outlet+tanggal itu (via audit read-only).
